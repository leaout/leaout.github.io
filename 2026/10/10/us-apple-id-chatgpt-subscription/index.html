为了订阅 ChatGPT，我把美区 Apple ID 重新折腾了一遍

最近为了订阅 ChatGPT Plus，我又把吃灰很久的美区 Apple ID 翻出来折腾了一遍。

本来以为登录、充值、订阅，十分钟搞定。结果一路踩坑：搜不到美区 App、付款跳银行卡、地址州和邮编填串、礼品卡买错区……最后总算跑通了。

这篇不是什么正经教程，更像是我自己折腾完之后的备忘录。如果你也在搞美区 Apple ID，或者想用 Apple 内购订阅 ChatGPT，可以少走点弯路。

一、先说最重要的：别碰共享美区 ID

网上确实能搜到一堆“免费美区 Apple ID”，看起来很方便，登上去就能下 App。

但我劝你别用。

原因很简单：那些账号是公共的，不知道多少人登过。你在“设置”里登录别人的 Apple ID，对方可以直接开“丢失模式”把你手机锁死，然后找你要钱解锁。这不是吓唬人，是真实发生过很多次的事。

而且你的通讯录、照片、文件，都有可能被同步到别人账号里。账号本身也不稳定，今天能用，明天可能就被封了。

所以，真要长期用，自己注册一个。免费，五分钟的事。

二、自己注册美区 Apple ID

准备两样东西：

  1. 一个没注册过 Apple ID 的邮箱。QQ 邮箱、Gmail、Outlook 都行。
  2. 一个美国地址。最好是免税州，比如俄勒冈、特拉华、新罕布什尔。

我当时用的是：

  • 街道：123 Main St
  • 城市：Wilmington
  • 州：DE
  • 邮编：19801
  • 电话：302-123-4567

注意，Wilmington 在特拉华州，不是俄勒冈州。电话 302 也是特拉华区号。你填的时候，州一定要选 DE，别看到“免税州”就顺手选 Oregon，不然邮编和州对不上，Apple 会打回来。

注册入口用浏览器无痕模式打开苹果官网的 Apple ID 页面，国家选美国，填邮箱、密码，手机号用国内的也能收验证码。

注册完之后，先别急着在手机设置里登 iCloud。只在 App Store 里登就行。

三、退出 App Store 的正确姿势

如果你之前登的是国区账号，要先退出。

路径是：

打开 App Store → 点右上角头像 → 滑到最底下 → 退出登录。

退出之后，再登你的美区账号。

也可以在“设置 → 你的名字 → 媒体与购买项目 → 退出登录”里操作。这个只退 App Store 和购买项目，不会退 iCloud。

千万别直接点设置最上面的“退出登录”，那会把整个 Apple ID 退掉，照片、通讯录、查找都可能受影响。

四、登录了，但搜不到美区 App

这是我遇到的第一个坑。

账号明明显示地区是美国，但 App Store 里搜出来的还是国区内容，或者干脆搜不到。

后来发现主要是两个原因：网络和缓存。

1. 网络必须走美国节点

App Store 会根据你的 IP 判断地区。你连着国内 Wi-Fi，就算账号是美区，它也可能给你加载国区内容。

我当时把代理切成美国节点，并且开全局模式，才正常。

如果你用的是规则模式，App Store 的流量可能没走代理，也会出问题。

2. 强制刷新 App Store 缓存

切换账号后，App Store 经常卡在旧缓存里。办法是：打开 App Store，在底部任意一个标签上连续点 10 次。比如“Today”“游戏”“App”“搜索”都行。点完之后屏幕会白一下，然后重新加载。

再不行就把 App Store 从后台划掉，重新打开，或者重启手机。

另外，把系统语言和地区也改成美国，会少很多事：

设置 → 通用 → 语言与地区 → iPhone 语言选 English (US)，地区选 United States。

五、订阅 ChatGPT，卡在付款方式

App Store 正常之后，我下载了 ChatGPT。

登录账号，点升级，选择 Plus，结果跳到付款页面，提示我要添加付款方式，然后直接跳银行卡。

原因很简单：Apple ID 余额不足。

Apple 的扣款逻辑是优先扣余额。余额不够，它就要求你绑卡。你绑国内卡大概率不行，美区账号要美区支付方式。

解决办法就是：先给美区 Apple ID 充值。

充值方式就是买美区 Apple Gift Card，然后兑换到账户里。

兑换路径：

App Store → 右上角头像 → 兑换充值卡或代码 → 输入兑换码。

充值之后，账户余额最好留够 20 美元以上。ChatGPT Plus 是 19.99 美元，但别刚好充 20，多充几刀更稳，比如 22 或 25。

余额够了，再回 ChatGPT App 里点订阅，就直接从余额扣了，不会再让你绑卡。

六、账单地址别填串

前面说的地址，再强调一遍。

123 Main St, Wilmington, DE 19801，这是特拉华州。电话 302-123-4567 也是特拉华区号。

如果你在表单里州选 Oregon，邮编却写 19801，Apple 会提示无效。

特拉华和俄勒冈都是免税州，所以用哪个都行，但信息要一致。

想用俄勒冈，就换成：

  • 城市：Portland
  • 州：OR
  • 邮编：97201
  • 电话：503-123-4567

别混着填。

七、礼品卡别买错区

这是另一个很容易踩的坑：其他区的礼品卡不能充美区账号。

Apple Gift Card 是锁区的。日区卡只能充日区，美区卡只能充美区。你拿一张非美区的卡去美区账号兑换，系统会直接拒绝，提示你必须在对应国家或地区兑换。

所以买之前一定要看清：United States / US / 美区。

八、美区礼品卡在哪买

淘宝上 $20 卖 142 块，算下来汇率 7.1，比实时汇率还贵。我反正没在淘宝买。

后来对比了几个渠道：

1. 美国苹果官网

最安全，没有之一。有双币信用卡的话，直接去美国苹果官网买 Gift Card，选金额，填邮箱，付款。缺点是国内卡有时会支付失败，换张卡或者换银行试试。

2. 支付宝

我当时是把支付宝地区切到旧金山，从出境/惠出境里搜“App Store & iTunes US”，能找到美区礼品卡。$20 大概 136 块上下，比淘宝便宜点。

但支付宝这个入口有时候会变，也可能触发风控限额。能买就买，买不了就换渠道。

3. 美国亚马逊

美亚也能买，选 Email Delivery。但美亚风控很严，新账号或者第一次买礼品卡，很容易被砍单，甚至要求你提供账单证明。适合有老账号的人。

4. 第三方礼品卡平台

像 OffGamers、SEAGM 这类，支持支付宝和信用卡。价格有时还行，但平台要自己甄别，别随便找个小站就买。

最后提醒一句：价格远低于正常汇率的卡，千万别碰。比如 $100 卖你 500 块以下，基本都是黑卡。兑换之后，你的 Apple ID 可能直接被封，得不偿失。

九、最后几句实在话

整个流程跑下来，其实不复杂：

  1. 自己注册美区 Apple ID，别用共享号。
  2. App Store 退出国区，登美区。
  3. 网络走美国节点，刷新 App Store 缓存。
  4. 买美区礼品卡，充值到 Apple ID。
  5. 在 ChatGPT App 里订阅，余额扣款。
  6. 地址用免税州，但州、邮编、电话要一致。

唯一麻烦的是礼品卡渠道和网络环境。但只要别贪便宜、别用共享账号，基本不会出大问题。

我现在是国区 ID 管 iCloud 和日常支付，美区 ID 只管 App Store 下载和订阅。两个分开，互不打扰，稳得很。

先写到这，后面再有新坑我再补。
